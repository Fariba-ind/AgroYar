# AgroYar

AgroYar is an Android agriculture reference app for searchable pesticide information and crop/pest use recommendations, with a Persian/English interface, theme controls, animated AgroYar splash branding, and app update awareness.

## Current scope

- Dashboard with three search paths:
  - pesticide / trade name / scientific name / active ingredient / formulation;
  - crop;
  - pest, disease, or weed.
- Pesticide detail view with active ingredient, concentration, formulation, category, mode of action, targets, registered crops, dose/application fields, restrictions, weather/water-stress cautions, and PHI where the source provides them.
- Detailed crop-use recommendation view with crop, target, recommended pesticide, formulation, dose, timing, source notes, and source page.
- Persian and English UI with RTL/LTR support.
- Light, dark, and system theme modes.
- Animated AgroYar launch/splash screen and app logo.
- About the developer section.
- Update check against the latest GitHub Release.

## Canonical data source

The project Word document is the canonical data source. It contains a source catalog of 347 pesticide active-ingredient/mixture records and 389 detailed use-recommendation rows.

The current runtime APK intentionally uses a **validated Word-derived preview subset** (15 pesticide records and 25 recommendation rows) while the complete source is being re-imported with integrity checks. The app must not silently fall back to fabricated pesticide data.

For field use, always verify rates, registrations, PHI/REI, incompatibilities, restrictions, and other safety-critical details against the current product label and authoritative jurisdiction-specific sources.

## Installation and debug signing

Development APKs are signed with a repository-specific **debug-only** key so CI builds keep the same signing identity and can update one another reliably.

If an AgroYar APK from an earlier development build is already installed, Android may reject the first upgrade because those historical CI builds used different autogenerated debug certificates. In that specific case, uninstall the old development build once and install the current APK. Future debug builds produced by this repository will share the stable development signature.

The debug keystore must never be used to sign a production or Play Store release.

## Compatibility and validation

- Minimum Android: API 23 (Android 6.0)
- Compile / target SDK: 36
- Kotlin + Jetpack Compose + Material 3
- JDK 17 / Gradle 8.13

CI validates generated database assets, runs Android Lint and unit tests, verifies the APK ZIP/signing structure, and performs emulator smoke tests on API 23 and API 35. The smoke test installs the APK, verifies replacement installation, launches the animated splash, checks the transition to `MainActivity`, exercises key UI routes, and scans logcat for app crashes/ANRs.

## Build

With Gradle 8.13 and JDK 17 installed:

```bash
gradle :app:lintDebug :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions uploads the tested `app-debug.apk` as `AgroYar-debug-apk`.
