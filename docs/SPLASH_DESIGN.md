# AgroYar splash design

The Android launcher now opens a dedicated animated Compose splash screen before `MainActivity`.

Design language:
- vector AgroYar sprout + agricultural field logo
- cream-to-green agricultural gradient
- soft halo rings and light particles
- fade/scale entrance and exit animation
- Persian subtitle: «همراه هوشمند کشاورزی»
- shared vector mark used as the application icon

The splash is implemented in code rather than as a raster-only screen so it stays crisp across Android screen sizes and densities.
